AI通知ランプ 初期設定マニュアル

はじめて使うときの設定のしかたです。設定は AI が代わりに進めます。あなたは、AI の質問に答えて、言われた操作をするだけです。

かかる時間5〜10 分ほど（途中でアプリを 1 回開き直します）
使えるパソコンWindows 10 / 11、Mac（USB-C の口があるもの）
使える AIパソコンに入れた Claude（Claude Code）または Codex のアプリ。
ブラウザで使う版（Web 版・クラウド版）や、ふつうのチャットでは使えません（パソコンの USB に届かないため）。
① 挿す② 文を送る③ 質問に答える④ 緑を確かめる⑤ 開き直す⑥ 承認（Codex だけ）⑦ 光れば完了

1ランプを USB に挿す

  • パソコンの USB の口に直接挿してください。USB ハブ（口を増やす機器）は使わないでください。
  • 挿すと虹色が流れます。これで準備 OK です。
  • Mac の場合：はじめて挿すと「アクセサリの接続を許可しますか？」と出ます。「許可」を押してください（「許可しない」を押すとランプと通信できません。押してしまったら、抜いて挿し直します）。

2AI に文を送る

Claude か Codex のアプリを開き、新しい会話に次の文を送ります。

コピーして貼れる場合（リベシティのメッセージでお送りした文）:

AI通知ランプを設定してください。手順は https://github.com/kisimenn/ai-lamp の README のとおりにお願いします。
・README のコマンドだけを使い、自分でスクリプトを書いたり設定を手で書き換えたりしないでください
・実行できないときは、実行ボタン付きの形で私に頼んでください
・最後に、アプリの開き直し（Codex はフックの承認も）を、見本の画像を開いて案内してください

手で打つ場合（案内の紙の文）:

AI通知ランプを設定して。手順は github.com/kisimenn/ai-lamp の README のとおりに。

3AI の質問に答える

  • 「ダウンロードしていいですか？」「実行していいですか？」などと聞かれたら、許可してください。
  • 「自分で実行してください」と言われたら、AI が表示した実行ボタンを押すか、表示されたコマンドをそのまま実行してください（AI の安全の設定によっては、AI が自分では実行できないことがあります）。
  • 「Claude と Codex のどちらで使いますか？」と聞かれます。ふだん使う AIを答えてください（両方でも大丈夫です）。使わない方は設定しないので、そのぶん案内が短くなります。
  • 「既読で消える機能を使いますか？」と聞かれます。おすすめは「使う」です。
    ランプが緑や橙に点いたあと、AI のアプリの画面でマウスやキーボードを触るだけで、ランプが消える機能です（見るのは「どのアプリが前にあるか」と「最後に触った時刻」だけで、打った文字は見ません）。
    使わない場合、ランプを消すには、ランプの先の「タッチ」（光る所のまわり）に触れる必要があります。あとから AI に頼んで変えられます。
    Mac の場合（この機能は試験中です）：使うと、Mac の画面に「バックグラウンド項目が追加されました」と出ることがあります。ランプの機能なので、そのままで大丈夫です。

4ランプが緑に光ったか答える

設定の最後に、確認のためランプが緑に 2 秒光ります。設定を始める前に AI が「ランプを見ていてください」と予告するので、ランプを見ていてください。AI に「光りましたか？」と聞かれたら答えます。

光らなかったら：そう答えてください。AI が案内します。ランプを別の USB の口に挿し直すと光ることがあります。

この緑は「ランプが見つかった」という確認です。AI と連動して光るかどうかは、⑦で確かめます。

5アプリを終了して、開き直す

新しい設定を読み込むために、③で答えた AI のアプリを一度終了して開き直します（両方で使う場合は両方）。AI が見本の画像と終わらせ方を一緒に案内します（画像はブラウザにも開くので、アプリを閉じたあとも見られます。画像が見えないときは、AI が書いた URL を押してください）。

右上の「×」（Mac は左上の赤い丸）では、画面が閉じてもアプリが裏で動き続け、新しい設定が使われないことがあります。必ず下の方法で終了してください。パソコンの再起動は要りません。
Windows の Claude左上の「≡」→「ファイル」→「終了」
Windows の Codexメニューの「ファイル」→「ChatGPT を終了」（Codex でも、メニューには「ChatGPT」と出ます）
Macアプリの画面を前に出して、「command」キー（スペースキーのとなり）を押したまま「Q」を押します。
画面のいちばん上のメニューで、アプリの名前 →「〇〇を終了」でも同じです。
開き直したら、さっきの設定の会話に戻って「開き直した」と送ってください。AI が続きを案内します。

6フックを承認する（Codex で使う人だけ・1 回だけ）

Codex は、ランプを動かすための許可（フックの承認）が 1 回だけ必要です。Claude だけの人は飛ばします。

  1. 入力欄の下に出る、黄色い点付きのアイコンを押します。
  2. 「フックの確認」が開いたら、lamp-hook（または lamp.ps1、Mac は lamp.pl）と書かれたランプ用のものを許可します。全部ランプ用なら「すべて許可」、ほかのものも並んでいれば、ランプ用だけ選んで「選択した項目を許可」。
  3. できたら、AI に「できた」と送ります。

アイコンが見当たらないときは、承認済みのこともあります。AI にそう伝えてください（「設定 → Hooks」で確かめられます）。

7光れば完了

  1. 新しい会話を開いて「こんにちは」と送ります。
  2. 送ったあとランプが青、返事が終わると緑に光ります。返事が早いと、青は一瞬で緑に変わります。緑に光れば成功です。
  3. 設定の会話に戻って「光った」と送ってください。これで設定は完了です。
10 秒たっても光らなかったら：設定の会話に戻って、AI にそう伝えてください。AI がよくある原因を確かめ、記録（会話の中身は入っていません）を見て、どこで止まっているかを調べます。

光り方の意味

ランプ意味あなたは
青（ゆっくり）AI が作業中待っていて大丈夫
緑作業が終わった結果を見に行く
橙（点滅）あなたの出番（許可や質問）画面を見て操作する

ランプの先の「タッチ」（光る所のまわり）に触れると消えます（設定は消えません）。光り方は、AI に頼めば変えられます。たとえば「作業中の色を紫にして」「夜は暗くして」「作業が終わったら虹色でお祝いして」「作業が10分を超えたら色を変えて」「やさしい光り方にして」（ほかに 派手・夜用・集中）。

困ったとき

こんなときやること
挿しても虹色にならない別の USB の口に挿し直す。USB ハブを使っていれば外して、パソコンに直接挿す
緑の確認で光らないAI に「光らない」と伝える（AI が順番に案内します）
AI に「自分で実行して」と言われた表示された実行ボタンを押す（または表示されたコマンドを実行する）
開き直しても光らないアプリを「×」で閉じていないか確かめ、⑤の方法で終了し直す。Codex は⑥の承認を確かめる。分からなければ AI に「光らない」と伝える（AI が記録を見て調べます）
途中で分からなくなった設定の会話で、AI に「いまどこまで終わった？」と聞く
それでもうまくいかないリベシティのメッセージでご連絡ください

外したいときは、AI に「AI通知ランプの設定を外して。手順は github.com/kisimenn/ai-lamp の README のとおりに。」と送ります。
