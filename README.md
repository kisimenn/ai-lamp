# AI通知ランプ 設定手順（AI向け）

この文書は、お客さんに頼まれた AI（Claude Code または Codex）が読んで実行するための手順です。
AI の作業状態を USB ランプの色で知らせます（作業中=青 / 完了=緑 / あなたの出番=橙）。

## AI への約束ごと（必ず守る）
- **スクリプトや設定を自分で書かない。** 下に書いたコマンドだけを、書いたとおりに実行する。設定ファイル（settings.json・hooks.json・config.toml）を手で編集しない。
- **COM ポートを自分で調べて判断しない。** ランプが見つかるかどうかは、スクリプトが表示する結果をそのまま伝える。
- お客さんは機械に詳しくないことが多い。専門用語を避けて、やさしい日本語で短く話す。
- お客さんにしてもらうのは「コマンドの実行を許可する」「（Windows のときだけ）既読で消える機能を使うか答える」「ランプが光ったか答える」「見本の画像が見えたか答える」「アプリを開き直して、この会話に戻る」「（Codex のときだけ）フックを1回承認する」「青 → 緑 と光ったか答える」だけにする。
- クラウドで動く版（Web の Claude Code、Codex のクラウド）では使えない（パソコンの USB に届かないため）。その場合はそう伝えて終わる。

## 案内のしかた（必ず守る）
- **ひとつずつ進める。** 「見本の画像を見せる → 操作をひとつ案内する → できたか聞く → 返事を待ってから次へ」。2 つ以上の操作を一度にまとめて説明しない。特に、アプリの開き直しとフックの承認は**別々の返事**で案内する。
- **毎回、短く進み具合を伝える。** 例:「ランプの確認まで終わりました。次はアプリの開き直しです。」
- **4 つを区別して伝える。** 「設定できた（スクリプトが OK）」「ランプが見つかった（スクリプトの表示）」「実物が光った（お客さんの返事）」「AI と連動した（青 → 緑 をお客さんが見た）」。お客さんが見ていないことを「できた」と言わない。**「設定完了」と言うのは、連動が確かめられたときだけ**。
- **見本の画像は、操作を案内する前に必ず見せて、見えているか聞く。** 見せ方は 2 つとも行う:
  1. お客さんのブラウザで開く。Windows: `Start-Process '<画像のURL>'`、Mac: `open '<画像のURL>'`（アプリを閉じても、ブラウザの画像は残る）
  2. 返事の中にも画像として載せる（`![見本](<画像のURL>)`）。画像が出ない画面のために、URL もそのまま書いておく
  ブラウザで開くコマンドが止められたり失敗したりしたら、お客さんに URL を押して開いてもらう。開くコマンドが成功しただけで「見えた」と思わない。**「見本の画像は見えていますか？」と聞いて、返事を待つ。**
- **原因を決めつけない。** たとえば別の USB ポートで光っても、「前のポートが壊れている」「古いパソコンだから」と言い切らない。

## はじめに：どれに当てはまるか
| 使っている AI | パソコン | 進む先 |
|---|---|---|
| Claude Code | Windows | 「1. ダウンロード（Windows）」 |
| Claude Code | Mac | 「1. ダウンロード（Mac）」 |
| Codex | Windows | 「1. ダウンロード（Windows）」。開き直したあと「4. Codex のフックを承認」も行う |
| Codex | Mac | 「1. ダウンロード（Mac）」。開き直したあと「4. Codex のフックを承認」も行う |

どちらの AI でも同じ設定スクリプトを使います。スクリプトが、パソコンに入っている Claude Code と Codex の両方をまとめて設定します。

最初にお客さんへ伝える（これだけ。長くしない）:
> 設定は全部で 5〜10 分ほどです（途中でアプリを 1 回開き直します）。ランプの設定ファイルをダウンロードして、設定を実行します。途中で実行の許可を求められたら許可してください。
> ランプはパソコンの USB の口に挿しておいてください。USB ハブ（口を増やす機器）を使っている場合は、パソコンに直接挿してください。

Mac のときは、あわせて「ランプを挿したときに『アクセサリの接続を許可しますか？』と出たら、『許可』を押してください」と伝える（許可しないとランプと通信できない）。

## 1. ダウンロード（Windows）
PowerShell で、次をそのまま実行する（`%USERPROFILE%\.cache\ai-lamp\src` に置く）。
```powershell
$d = Join-Path $env:USERPROFILE '.cache\ai-lamp\src'; Remove-Item -Recurse -Force $d -ErrorAction SilentlyContinue; New-Item -ItemType Directory -Force -Path $d | Out-Null; Invoke-WebRequest -UseBasicParsing -Uri 'https://github.com/kisimenn/ai-lamp/archive/refs/heads/main.zip' -OutFile (Join-Path $d 'repo.zip'); Expand-Archive -Force (Join-Path $d 'repo.zip') $d; Get-ChildItem $d -Directory | Select-Object -ExpandProperty FullName
```
最後に表示されたフォルダ（`...\ai-lamp-main`）を、次の手順で使う。

## 1. ダウンロード（Mac）
ターミナルで、次をそのまま実行する（`~/.cache/ai-lamp/src` に置く）。
```bash
d="$HOME/.cache/ai-lamp/src"; rm -rf "$d"; mkdir -p "$d" && curl -fsSL -o "$d/repo.zip" https://github.com/kisimenn/ai-lamp/archive/refs/heads/main.zip && unzip -q -o "$d/repo.zip" -d "$d" && ls -d "$d"/*/
```
最後に表示されたフォルダ（`.../ai-lamp-main/`）を、次の手順で使う。

## 2. 設定を実行して、ランプが光るか確かめる
**Windows のときだけ、実行する前に1回だけ聞く**:「ランプが緑か橙に点いたあと、AI のアプリの画面でマウスかキーボードを触ると、ランプが消える機能（既読で消える機能）を使いますか？」
- 使う → 下の Windows のコマンドの最後に ` -Watch` を付ける
- 使わない → ` -NoWatch` を付ける
- Mac にはこの機能が無いので聞かない

- Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File "<1で表示されたフォルダ>\setup.ps1" -Watch`（使わないときは `-NoWatch`）
- Mac: `bash "<1で表示されたフォルダ>/setup.sh"`

結果は「OK（成功）」「--（飛ばした）」「NG（失敗）」で1行ずつ表示される。**区別したまま**、短くお客さんに伝える。スクリプトの最後に出る「開き直し」「光り方」の案内は、**ここではまとめて伝えない**（3〜6 で、ひとつずつ伝える）。

最後の行がランプの確認で、ランプが見つかれば緑に2秒光らせている。「見つかりました」と出ても、実物が光ったとは限らない。お客さんに聞いて、**返事を待つ**:
> 確認のため、ランプを緑に 2 秒ほど光らせました。光りましたか？

- 光った → 「ランプの確認まで終わりました。次はアプリの開き直しです。」と伝えて「3」へ
- 光らない・見逃した → 「7. 光らないとき」へ。実物が光るのを確かめてから「3」へ進む

## 3. アプリを開き直す（終わったら、この会話に戻ってもらう）
**設定したアプリだけ**を終了して開き直してもらう（スクリプトの最後の案内に、どのアプリかが出ている）。
1. Windows のときは、まず見本の画像を見せて（「案内のしかた」のとおり 2 つの方法で）、「見本の画像は見えていますか？」と聞き、返事を待つ。Claude と Codex の両方を設定したときは、2 枚とも見せる
   - Claude アプリ: https://raw.githubusercontent.com/kisimenn/ai-lamp/main/docs/claude-quit.png
   - Codex アプリ: https://raw.githubusercontent.com/kisimenn/ai-lamp/main/docs/codex-quit.png
   - Mac は見本の画像が無いので、この 1 は飛ばす
2. 理由と終わらせ方と戻り方を、下の例のとおり 1 回で伝え、返事を待つ。**フックの承認はまだ言わない。**
   - Windows の Claude アプリ:
     > 右上の「×」では、画面が閉じても裏でアプリが動き続け、新しい設定が使われないことがあります。見本の画像のとおり、左上の「≡」→「ファイル」→「終了」を選んでください。開き直したら、**この会話に戻って「開き直した」と送ってください。** パソコンの再起動は要りません。
   - Windows の Codex アプリ:
     > 右上の「×」では、画面が閉じても裏でアプリが動き続け、新しい設定が使われないことがあります。見本の画像のとおり、「ファイル」→「ChatGPT を終了」を選んでください（Codex でも、メニューには「ChatGPT」と出ます）。開き直したら、**この会話に戻って「開き直した」と送ってください。** パソコンの再起動は要りません。
   - Mac（Claude・Codex とも）:
     > 左上の赤い丸（×）では、画面が閉じてもアプリが動き続け、新しい設定が使われないことがあります。アプリの画面を前に出した状態で、キーボードの「command」（スペースキーのとなり）を押したまま「Q」を押して終了してください（画面のいちばん上のメニューで、アプリの名前 →「〇〇を終了」でも同じです）。開き直したら、**この会話に戻って「開き直した」と送ってください。** パソコンの再起動は要りません。
   - 両方を設定したときは、「両方とも終了して、開き直してください」とし、終わらせ方を 2 つ並べる
3. 「開き直した」と返事が来たら:
   - Codex を設定した → 「4. Codex のフックを承認」へ
   - Claude だけ → 「5. AI との連動を確かめる」へ

## 4. Codex のフックを承認（Codex を使っている人だけ・1回だけ）
Codex は、ランプ用のフックを1回承認しないと光らない（承認するまで黙って飛ばされる）。
1. 「次は、ランプを動かすための許可です。」と伝え、見本の画像を見せて（2 つの方法で）、「見本の画像は見えていますか？」と聞き、返事を待つ
   - アイコンの画像: https://raw.githubusercontent.com/kisimenn/ai-lamp/main/docs/hook-icon.png
2. 見えたら案内して、返事を待つ:
   > 入力欄の下に、見本と同じ「黄色い点付きのアイコン」が出ているはずです。押して「フックの確認」を開き、`lamp-hook`（または `lamp.ps1`、Mac は `lamp.pl`）と書かれたランプ用のフックを許可してください。全部ランプ用なら「すべて許可」、ほかのフックも並んでいれば、ランプ用だけ選んで「選択した項目を許可」です。できたら「できた」と送ってください。アイコンが見当たらなければ、そう教えてください。
- アイコンのとなりの文字は Codex の設定で変わるので、目印にしない。
- アイコンが出ないときは、承認済みのこともある。設定 → Hooks で確かめてもらう（決めつけない）。
- ターミナルの Codex は `/hooks` で承認する。
- 同じ承認を二か所で求めない。承認済みと分かったら何度も頼まない。
- 「できた」と来たら「5. AI との連動を確かめる」へ。

## 5. AI との連動を確かめる
「2」の緑 2 秒は「ランプが見つかった」確認で、AI との連動の確認ではない。ここで確かめる。
> 新しい会話を開いて「こんにちは」と送ってみてください。送ったあと青に光り、返事が終わったら緑に変わるか見てください。見終わったら、**この会話に戻って**結果を教えてください。

- 青 → 緑 と光った → 「設定はすべて完了です。」と伝えて「6」へ
- 光らない → Codex なら承認できているか（4）を確かめる。それでもだめなら「7. 光らないとき」
- 青になるまで数秒かかることがある（最初の数回や、パソコンが忙しいとき）。秒数を約束しない
- Codex で橙になるのは「許可を求められたとき」だけ（Codex にはエラーで止まった合図が無い）

## 6. 最後に、光り方を変えられることを紹介する
連動が確かめられたあとに、短く紹介する。押しつけず「気が向いたら」くらいで。
> ちなみに、ランプの光り方は、私に頼めば変えられます。たとえば、
> - 「作業中の色を紫にして」
> - 「夜は暗くして」
> - 「作業が終わったら虹色でお祝いして」
> - 「作業が10分を超えたら色を変えて」
> - 「やさしい光り方にして」（ほかに 派手・夜用・集中）
> 気が向いたら言ってください。

頼まれたら、ランプのスキル（lamp-setup）の「光り方を変えて と言われたら」のとおりに、好みのファイルだけを書き換える。

## 7. 光らないとき（この順で、深追いしない）
1. 「ランプを USB から抜いて、挿し直してください。**虹色**に光りましたか？」と聞く。
2. 虹色に光らない、または「見つかりました」と出たのに緑に光らない → **別の USB の口に挿してもらう**（口によって光らないことがある）。USB ハブを使っていれば外して、パソコンに直接挿してもらう。そのあと、この下の 3 のランプの確認をやり直す。
3. 虹色に光った → （Mac のときは）「挿したときに『アクセサリの接続を許可しますか？』と出ましたか？『許可しない』を押していたら、もう一度挿し直して『許可』を押してください」と聞く。そのうえで、ランプの確認だけをやり直す:
   - Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File "<1のフォルダ>\plugins\ai-lamp\scripts\lamp-test.ps1"`
   - Mac: `/usr/bin/perl "<1のフォルダ>/plugins/ai-lamp-mac/scripts/lamp.pl" test`
   表示された結果をそのまま伝え、緑に光ったか聞く。
4. Arduino IDE などシリアル通信を使うソフトが開いていれば、閉じてもらってからもう一度 3。
5. **2回やってもだめなら**、パソコンを再起動してから、もう一度この手順を最初から頼んでもらうよう伝えて終わる。
6. 光るようになったら、止まっていた所に戻る（「2. 設定を実行」で止まっていたら「3. アプリを開き直す」へ、「5. AI との連動」で止まっていたら、もう一度「こんにちは」で確かめる）。

## 外したいと言われたら
1 と同じ方法でダウンロードし、Windows は `uninstall.ps1`、Mac は `uninstall.sh` を実行する（Claude Code のプラグイン、Codex のフック、ランプの記録をまとめて外す）。そのあとアプリを開き直してもらう。
